# A full import keeps the carbon footprints that OVHcloud no longer gives

`--full` clears an account's data and imports it again, which loses nothing for its bills,
as OVHcloud keeps all of them. Its carbon calculator only gives the last 24 months, which
every import asks for again and replaces: a full import, as the others, keeps the older
carbon footprints, which OCM could not get back.
