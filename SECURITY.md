# Security policy

## Supported versions

Security fixes go into the latest release. Please check that the issue still
happens on it before reporting.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Report it privately
through [GitHub private vulnerability reporting](https://github.com/mmaudet/ovh-cost-manager/security/advisories/new),
with a description of the issue, the steps to reproduce it and the affected
version.

Once a fix is released, it is listed under **Security** in the
[changelog](CHANGELOG.md) and, when it matters to users, published as a
[GitHub security advisory](https://github.com/mmaudet/ovh-cost-manager/security/advisories).
